# PDF & Domain Traceability Matrix

This document provides a comprehensive traceability audit mapping original Wyckoff Method and Volume Spread Analysis (VSA) requirements (from domain reference documentation, codified specifications, and `AGENTS.md`) against the active Python implementation in `wyckoff-stock-screener`.

## Classification Standard
- **IMPLEMENTED**: Exact or directly equivalent quantified behavior exists with test verification.
- **SUPERSEDED**: Newer implementation deliberately replaces older behavior with documented rationale (e.g., bug fixes, bounded lookaheads, dynamic scaling).
- **PARTIAL**: Behavior is partially implemented or functions as an explicit approximation.
- **MISSING**: Stated requirement is not implemented in the current codebase.
- **NOT APPLICABLE**: Older specification is no longer applicable to the current architecture.

## 2. Summary of Superseded & Partial Items

1. **Spread Ratio ATR Denominator (`SUPERSEDED`)**:
   - *Rationale*: Simple rolling mean ATR (`use_wilder=False`) was selected over smoothed Wilder ATR to react immediately to localized bar spread expansion/contraction.
2. **ST and LPS Search Window Bounds (`SUPERSEDED`)**:
   - *Rationale*: Original unbounded search resulted in scanning from an anchor event to the dataset end, creating combinatorial duplicates (e.g. 211 STs and 13,534 LPSs on ANANTRAJ). Bounded windows (`ST_MAX_BARS_AFTER_SC = 15`, `LPS_MAX_BARS_AFTER_ANCHOR = 20`) taking only the first qualifying bar per anchor resolved this combinatorial explosion.
3. **P&F Box Size Scaling (`SUPERSEDED`)**:
   - *Rationale*: Hardcoded static traditional lookup tables cannot cleanly support Indian equity denominations spanning from ₹10 to ₹100,000+. Dynamic percentage-of-price scaling (~1%) was implemented.
4. **P&F Anchor Staleness Check (`SUPERSEDED`)**:
   - *Rationale*: Prevented stale targets (e.g. 329.85 for APOLLO when price was 384.55) by invalidating count rows anchored to events older than 60 bars (`stale_anchor = True`, `pf_pts = 0.0`).
5. **Peer Analysis Score when Missing (`SUPERSEDED`)**:
   - *Rationale*: Defaulting to half credit fabricated confidence for unanalyzed factors. Fixed to score 0.0 points with `peer_analysis_skipped = True`.
6. **Prior Trading Range Support/Resistance (`PARTIAL`)**:
   - *Rationale*: `get_prior_trading_range` uses trailing $\min(\text{Low}) / \max(\text{High})$. Flagged as an approximation because in strong trending environments this can represent an advancing channel rather than horizontal range-bound accumulation.
